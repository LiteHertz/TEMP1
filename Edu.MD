# Edu

## Règlements

- Le but est de détruire les planètes adverses
- L'entièreté des personnes éliminées d'une équipe retournent sur le jeu lors de la destruction d'une planète
- Attraper un ballon ne libère pas un membre de l'équipe
- Lorsqu'un seul joeur est restant sur le jeu, il ne peut être éliminié par l'équipe adverse, mais seulement s'il reste deux planètes ou plus sur le jeu
- Vous avez le droit de vous placer devant les planètes afin de les protèger
